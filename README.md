# IIIT-Delhi Academic ERP System

A comprehensive desktop application built to manage academic workflows at IIIT-Delhi. This system provides a centralized platform for students to register for courses, instructors to manage grading, and administrators to handle campus maintenance tools.

## Key Features
* **Role-Based Access:** Specialized dashboards for Students, Instructors, and Admin.
* **Course Management:** Streamlined registration and automated grading systems.
* **Performance:** Implemented JDBC connection pooling to ensure efficient MySQL database interactions.
* **UI/UX:** Developed using Java Swing for a responsive desktop experience.

## Technical Stack
* **Language:** Java
* **Database:** MySQL
* **Connectivity:** JDBC with Connection Pooling
